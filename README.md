# Idle Adventurer

An Old School RuneScape inspired idle game that lives in the RuneLite sidebar. Your adventurer walks up to monsters and fights them on its own; you spend coins and loot on better weapons, armour, food, potions and prayers.

Work in progress. The game rules live in `com.idleadventurer.engine` and have no RuneLite dependencies.

## Running

`./gradlew run`
